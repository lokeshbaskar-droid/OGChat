OGChat Phase 4 — Test Checklist
===============================

[ ] Run npm install successfully on Windows.
[ ] Run npm start and open http://localhost:3000.
[ ] Open /api/ocr/status and verify available=true.
[ ] Upload a normal text-based PDF; confirm text extraction still works.
[ ] Upload a scanned PDF; confirm OCR runs and readable content is extracted.
[ ] Upload a mixed PDF with both text and scanned pages; confirm both kinds of pages are represented.
[ ] Ask a question about a specific page/topic and inspect the answer/source page context.
[ ] Test a low-quality scan and confirm errors are understandable rather than a server crash.
[ ] Confirm temporary ogchat-ocr-* directories are cleaned up after success/failure.
[ ] Confirm DOCX and text uploads still work.
